《键盘火力》隐私政策与用户服务协议

更新日期：2026年10月15日 | 生效日期：2026年10月15日

欢迎使用《键盘火力》游戏！我们深知个人信息对您的重要性。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。请您在使用本游戏前，仔细阅读并充分理解本政策的全部内容。

重要提示

在您点击"同意"按钮前，请特别知悉：

  1. 本游戏为单机游戏，本游戏自身将收集以下设备信息以保障正常运行：
    • Android ID：设备唯一标识符，用于识别设备和关联本地存档
    • 设备传感器信息：加速度计重力向量数据，用于检测设备倾斜状态以实现主菜单视差效果
    • 设备型号、操作系统版本、屏幕分辨率、CPU/GPU信息、OAID、GAID（Google 广告 ID）等运行环境参数与设备标识信息（OAID/GAID 用于广告归因与反作弊，详见下文"第三方SDK目录"）
  2. 为提供 TapTap 账号登录、实名认证及防沉迷服务，本游戏已接入 TapTap SDK（com.taptap.sdk）。在您同意本政策后，TapTap SDK 会收集您的 Android ID、OAID、GAID（Google 广告 ID，如设备装有 Google 服务）、IMEI、设备序列号、MAC 地址 等设备标识信息，以及设备品牌/型号/系统版本、网络类型、IP 地址、应用包名/版本等，用于完成登录认证、实名核验、防沉迷时长控制及合规记录。相关信息处理规则详见 TapTap 官方隐私政策。
  3. 为向您展示激励视频广告并支持游戏内"看广告领奖励"功能，本游戏已接入广告变现SDK（AdUp / TopOn AnyThink 聚合）及其调用的第三方广告网络（穿山甲、优量汇、快手联盟、百度联盟等）。在您同意本政策后，上述广告SDK会根据广告投放、监测归因和反作弊需要，收集包括但不限于以下信息并可能传输至第三方广告服务方服务器：
    • 设备标识信息：MAC地址、IMEI、OAID、GAID（Google 广告 ID）、Android ID、设备序列号等（因系统版本与权限情况而异）
    • 设备信息：设备品牌、型号、操作系统版本、屏幕分辨率、CPU/存储、语言时区等
    • 网络信息：IP地址、运营商、网络类型（Wi-Fi/移动数据）、Wi-Fi状态等
    • 位置信息（可选）：粗略/精确位置，用于广告定向与反作弊，您可拒绝授权
    • 应用信息：应用包名、版本号、安装列表、前后台状态等
    • 广告交互信息：广告请求、展示、点击、播放完成、转化等行为数据
  4. 与广告无关的游戏存档/设置信息主要存储于您的设备本地；广告及 TapTap 相关数据的处理请见下文"第三方服务说明"及"第三方SDK目录"。
  5. 您可以随时通过卸载游戏或清除应用数据来删除本地信息；第三方服务方按其各自隐私政策处理数据。

如您不同意上述内容，请点击"拒绝"退出本游戏。

二、我们如何使用收集的信息

我们将上述收集的个人信息用于以下用途：

  1. 运行游戏：使用设备和运行环境参数初始化游戏引擎，确保游戏在不同设备上正常渲染和运行
  2. 交互体验：使用加速度计传感器数据检测设备倾斜，提供主菜单视差效果
  3. 保存进度：将您的游戏存档和设置存储在本地设备，以便下次继续游戏
  4. 合规记录：记录您对隐私政策的同意状态，以满足《中华人民共和国个人信息保护法》等法律法规的要求

三、信息存储与保护

  1. 游戏存档与设置等业务数据主要存储于您的设备本地（应用私有目录）
  2. 广告SDK为完成广告请求、填充、展示、计费和反作弊，会通过网络将必要设备与广告交互信息发送至第三方广告服务方服务器
  3. 传感器数据不会被本游戏业务层持久化存储，仅在主菜单显示期间实时读取并即时处理
  4. 我们采用合理的措施保护您本地存储的游戏数据安全
  5. 当您卸载本游戏或清除应用数据时，本地存储的游戏信息将被删除；第三方广告服务方按其各自隐私政策处理数据

五、第三方服务说明

5.1 游戏引擎——Godot Engine

本游戏基于Godot Engine（版本4.x）开源游戏引擎开发。Godot引擎在初始化时会自动获取设备的运行环境信息（即上文第四节所述的操作系统版本、CPU/GPU信息、屏幕分辨率、渲染参数等），用于图形渲染管线初始化、着色器编译选择、性能监控等底层功能。

当项目中启用sensors/enable_gravity配置时，Godot引擎还会通过Android SensorManager API访问加速度计传感器，供游戏代码通过Input.get_gravity()接口获取重力向量数据。

数据处理方式：所有处理均在您的设备本地完成，Godot引擎不会将这些信息上传至任何外部服务器。

开源许可：Godot Engine基于MIT许可证开源，源码详见 https://godotengine.org/license
